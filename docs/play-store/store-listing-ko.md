# 스토어 등록정보 초안 (한국어)

Play Console > 성장 > 스토어 등록정보 > 기본 스토어 등록정보 에 그대로 붙여 넣으면 됩니다.

## 앱 이름 (최대 30자)

후보 3개. "nPlayer", "VLC" 같은 다른 회사 상표는 이름·설명에 넣지 않는 게 안전합니다(상표 정책 위반으로 거절될 수 있음).

| 후보 | 글자 수 | 느낌 |
|---|---|---|
| **Network Player - SMB 동영상 플레이어** | 29 | 지금 앱 이름 그대로, 검색어(SMB, 동영상 플레이어) 포함 |
| 폴더플레이 - PC 공유폴더 동영상 플레이어 | 24 | 한국어로 기억하기 쉬움 |
| 홈시어터 플레이어: SMB·NAS 동영상 | 22 | 용도가 바로 보임 |

> 앱 안에 보이는 이름은 `app/src/main/res/values/strings.xml`의 `app_name`입니다. 스토어 이름과 꼭 같을 필요는 없지만, 비슷하게 맞추는 걸 추천해요.

## 간단한 설명 (최대 80자)

```
PC 공유폴더 동영상·사진을 폰에서 바로! MKV·자막 지원, 한 손으로 편하게 보는 플레이어
```
(52자)

## 자세한 설명 (최대 4000자)

```
PC에 쌓아둔 영상, 이제 폰으로 옮기지 말고 바로 보세요.

Network Player는 윈도우 공유폴더(SMB)에 있는 동영상과 사진을 폰에서 바로 열어 보는 플레이어입니다. 파일을 내려받을 필요 없이, 같은 와이파이에 있는 PC의 폴더를 그대로 탐색하고 재생해요.

■ 이런 분께 딱 맞아요
• PC나 NAS에 영화·드라마·영상을 모아두신 분
• 침대에서 한 손으로 편하게 영상 보고 싶은 분
• MKV, 자막 파일 때문에 기본 플레이어가 답답하셨던 분

■ 공유폴더 연결
• PC 주소와 윈도우 계정만 넣으면 끝 (마이크로소프트 계정도 OK)
• 공유 이름을 몰라도 PC가 공유 중인 폴더 목록을 자동으로 보여줘요
• SMB2/SMB3 지원, SMB를 지원하는 NAS에서도 사용 가능

■ 거의 모든 영상 재생
• MP4, MKV, AVI, MOV, WMV, TS, M2TS, WEBM 등
• SMI, SRT, ASS 자막 자동 연결, 자막·음성 트랙 전환
• 하드웨어/소프트웨어 디코딩 선택, 문제 생기면 자동 전환

■ 손에 착 붙는 제스처
• 좌우로 밀면 영상이 실시간으로 따라오는 탐색
• 위아래로 밀어 밝기·볼륨 조절
• 더블탭 10초 이동, 꾹 누르면 2배속
• 화면 왼쪽/오른쪽을 꾹 누르면 이전/다음 영상

■ 한 손 조작용 플로팅 버튼
• 화면 위에 떠 있는 버튼 하나로 배속, 화면비, 회전, 자막, 화면 잠금까지

■ 보기 편한 탐색
• 썸네일 바둑판 보기(2~5열) / 목록 보기
• 이름·날짜·크기 정렬, 하위 폴더까지 이름 검색
• 좋아요 모아보기, 시청 기록 기반 랜덤 재생(안 본 영상만, N분 이상 등)
• 영상마다 화면비·회전 설정을 기억
• 사진 보기: 좌우 넘기기, 핀치 확대

■ 개인정보 걱정 없이
• 광고 없음, 분석 도구 없음, 회원가입 없음
• 모든 설정과 기록은 내 폰 안에만 저장돼요

※ PC와 폰이 같은 네트워크(와이파이)에 있어야 해요.
※ 오픈소스 라이선스는 앱 > 정보 화면에서 볼 수 있어요.
```

## 그래픽 자료

| 항목 | 규격 | 상태 |
|---|---|---|
| 앱 아이콘 | 512×512 PNG | `docs/play-store/icon-512.png` 준비됨 |
| 그래픽 이미지(Feature graphic) | 1024×500 PNG/JPG | 직접 제작 필요 (아래 아이디어) |
| 휴대전화 스크린샷 | 2~8장, 9:16 또는 16:9, 1080px 이상 권장 | 직접 촬영 필요 |

### 스크린샷 추천 구성 (6장)

영상 속 인물·저작권 있는 장면이 그대로 보이면 거절될 수 있어요. **직접 찍은 영상이나 저작권 없는 샘플 영상**(예: Big Buck Bunny, Sintel 같은 오픈 무비)으로 찍는 걸 추천합니다.

1. **바둑판 썸네일 화면** – 캡션: "PC 폴더를 썸네일로 한눈에"
2. **재생 화면 + 하단 제어바** – "MKV도 자막도 그냥 재생"
3. **좌우 탐색 중 화면** (미리보기가 따라오는 순간) – "밀면 영상이 따라오는 탐색"
4. **플로팅 옵션 펼친 화면** – "한 손으로 배속·화면비·회전"
5. **공유폴더 추가 화면** – "주소와 계정만 넣으면 연결 끝"
6. **좋아요/랜덤 재생 대화상자** – "안 본 영상만 랜덤으로"

캡션은 스크린샷 위에 큰 글씨로 얹으면 훨씬 눈에 잘 띕니다. 원하시면 제가 캡션 들어간 스크린샷 프레임도 만들어 드릴게요.

### 그래픽 이미지 아이디어 (1024×500)
파란 배경(#1F6FEB) 왼쪽에 앱 아이콘, 오른쪽에 "PC 공유폴더 영상, 폰에서 바로" 한 줄 + 재생 화면 폰 목업.
