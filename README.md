# Network Player

윈도우 공유폴더(SMB)의 동영상과 사진을 보는 개인용 안드로이드 플레이어. iPhone nPlayer의 사용감을 목표로 한다.

## 진행 상황

- [x] 1단계: SMB 공유폴더 추가/연결 테스트, 폴더 탐색, 사진 보기 (좌우 넘기기, 핀치 확대)
- [ ] 2단계: 동영상 스트리밍 재생 + 하단 제어바
- [ ] 3단계: 제스처 (좌우 탐색 시 영상 실시간 이동, 밝기/볼륨) + 한 손 조작용 플로팅 옵션 버튼
- [ ] 4단계: 이어보기, 최근 목록 등 다듬기

## APK 받기

GitHub의 **Actions** 탭에서 최신 "Build APK" 실행을 열고, 아래쪽 Artifacts의 `network-player-apk`를 받아 압축을 풀면 `app-debug.apk`가 있다.
저장소에 들어 있는 고정 디버그 키로 서명되므로, 새 버전을 받아 설치하면 기존 앱 위에 그대로 업데이트된다.

## 공유폴더 연결 팁

- PC 주소: 윈도우 `ipconfig`의 IPv4 주소 (예: `192.168.0.10`)
- 공유 이름: 폴더 속성 > 공유 탭에 나오는 이름 (`\\PC\Videos`라면 `Videos`). 주소 칸에 `\\192.168.0.10\Videos`를 통째로 붙여넣어도 된다.
- 사용자 이름/비밀번호: 윈도우 로그인 계정. 마이크로소프트 계정이라면 이메일 주소와 그 비밀번호.

## 빌드

```
./gradlew assembleDebug
```
